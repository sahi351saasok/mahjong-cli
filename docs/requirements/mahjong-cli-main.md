# 要件定義書

## 概要

コマンドライン上で動作する、リーチ麻雀のルールに則った4人打ち麻雀シミュレータ。
プレイヤーは全員コンピュータ（CPU）として対局を行い、半荘を1回プレイして最終結果を標準出力に表示する。

## 目的

CLI上で完結する麻雀の対局シミュレーションを提供する。
打牌選択、リーチ判断、鳴きの判断などの思考ロジックをソフトウェアとして実装し、思考ロジックの違いによる対局成績の違いを分析する。

## 用語定義

| 用語 | 説明 |
| --- | --- |
| 半荘 | 東場・南場を1回ずつ行う対局単位 |
| 東風戦 | 東場のみを行う対局単位 |
| 局 | 半荘・東風戦を構成する1回の親の交代までの単位（例: 東1局） |
| 本場 | 連荘やノーテン罰符などにより加算されるカウンター |
| 手牌 | プレイヤーが手元に持つ牌（通常13枚、ツモ時14枚） |
| 副露 | ポン・チー・カンにより他家の牌を鳴くこと |
| 和了 | 役が成立し、上がること |
| 役 | 和了に必要な手牌の型（リーチ、タンヤオ、ピンフ等） |
| ドラ | 点数計算時に加算対象となる特定牌 |
| 流局 | 誰も和了せずに局が終了すること |

## 対象ユーザー

開発者自身によるルール実装の検証・学習用途

## 機能要件

### ゲームモード

- 半荘戦（東場・南場）
- 1局のみ

### プレイヤー構成

CPU（自動プレイヤー）の4人

### 対局の流れ

1. 起家（東家）を決定する
2. 配牌を行う（各プレイヤーに13枚配る）
3. 各局を以下のサイクルで進行する
   - ツモ（山から1枚取得）
   - 打牌（手牌から1枚選択して捨てる）
   - 他家の打牌に対する副露判定（ポン・チー・カン・ロン）
   - リーチ宣言判定
   - 和了判定（ツモ・ロン）
   - 流局判定（山牌が尽きた場合）
4. 局の結果に応じて点数を移動し、連荘・親交代を判定する
5. 半荘（または東風戦）終了条件を満たしたら対局を終了する
6. 最終順位・最終点数を標準出力に表示する

### 麻雀ルール仕様

Abema TVで開催されているMリーグのルールに準拠する。

- 牌: 萬子・筒子・索子（各1〜9、4枚ずつ）、字牌（東南西北白發中、各4枚）の合計136枚
- リーチ、ツモ、ロン、ポン、チー、カン（明槓・暗槓・加槓）に対応する
- 役判定: 標準的な役（リーチ、タンヤオ、ピンフ、役牌、一気通貫、対々和、七対子、国士無双 等）に対応する
- ドラ表示牌・裏ドラ（リーチ時の和了に対して）に対応する
- 点数計算: 符・翻計算に基づく点数算出、および満貫以上（跳満・倍満・三倍満・役満）の判定を行う
- 特殊な流局条件（九種九牌、四家立直、四風連打、三家和了、四槓散了 等）は対応不要
- 喰いタンあり
- 赤ドラあり
- 対局開始時の各プレイヤーの持ち点は25000点
- 対局終了後、各プレイヤーの持ち点の増減をもとに、1000点につき1ポイントとして換算する
- 1位には +50ポイント、2位には +10ポイント、3位には -10ポイント、4位には -30ポイントを加算する
- 同一の順位が複数名いる場合は、加算ポイントを人数で按分する

### 入出力仕様（CLI）

- 入力:
  - コマンドライン引数:
    - ゲームモード (--mode)
      - a: 半荘を実行（デフォルト）
      - b: 1局のみ実行
- 出力:
  - 標準出力:
    - 各局の開始時点の情報（局・本場・親・ドラ表示牌）
    - 打牌・鳴き・リーチ等のアクションログ
    - 和了時の役・符・点数・手牌の表示
    - 半荘終了時の最終順位・最終点数・ポイント
    - 流局時は各プレイヤーのテンパイの有無を表示し、テンパイしているプレイヤーの手牌を表示
  - テキストログ:
    - `logs/<対局開始の年月日時分秒>.txt` に牌譜を保存

### CPU（自動プレイヤー）仕様

- CPUのプレイヤーは以下の思考ロジックに従い自動で進行する
  - 打牌選択の判断：
    - 牌効率を最優先
    - 高い役作りを最優先
    - 他家に振り込まないことを最優先（他家がリーチしたら安全牌を切って降りる）
  - リーチの判断：
    - テンパイしたら即リーチ
    - 手牌が満貫以上の場合のみリーチ
  - 鳴きの判断：
    - 最速でテンパイを目指す
    - 一向聴の場合のみ鳴く
    - 自身の手牌が満貫以上の場合のみ鳴く
- CPUの思考ロジックは差し替え可能な設計とする（将来的な強化学習・戦略変更を見据える）
- CPUの各プレイヤーの名前や思考ロジックの種類は、外部定義ファイル `config/playsers.yaml` で指定する
