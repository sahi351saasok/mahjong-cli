# 麻雀ゲームのログ出力仕様

## 標準出力

### 局の開始時

- 各局の開始時点の情報（局・本場・親・ドラ表示牌）

### 局の終了時

- 流局時は、各プレイヤーのテンパイの有無を表示し、テンパイしているプレイヤーの手牌を表示
- 和了時は、和了の役・符・点数・手牌を表示
- 1局終了時の各プレイヤーの点数を表示（前局からの増減も合わせて表示）
- 1局終了時の各プレイヤーの河を表示

### 半荘終了時

- 各プレイヤーの最終順位、最終点数、ポイント

## テキストログ

- 出力先ディレクトリは `./logs`
- 出力先ファイル名は `<麻雀ゲームを開始した年月日時分秒>.csv`
- ログには各プレイヤーのすべての行動と結果（打牌、鳴き、和了役など）を記録する
