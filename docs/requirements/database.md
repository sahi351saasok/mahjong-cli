# 麻雀ゲーム データベース要件

## 処理要件

### データの記録

局の終了時に、各プレイヤーの和了の有無、副露の有無、和了時の打点、リーチの有無、和了役を記録する。
半荘の終了時に、各プレイヤーの最終ポイント数と最終順位を記録する。

### データの集計と表示

半荘の終了時に、以下の情報を標準出力に表示する。
- プレイヤーごとの通算ポイント数、平均順位、和了率、副露率、平均打点、リーチ率
- 出現した役の種類と通算回数（回数の多い順に並べる。0回の役は表示しない。）

# システム要件

データベースエンジンには SQLite を使用する。
データベースはローカルファイルとして保存する。
データベースファイルが存在しない場合は新たに作成する。
